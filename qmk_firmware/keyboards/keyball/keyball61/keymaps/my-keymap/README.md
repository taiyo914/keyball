# Keyball61 の使い方

Keyball61 を初めて使う人に向けて、使い方の要点をまとめたものです。キーの配置は Mac で使う前提で作ってあります。

## 1. はじめに

**Keyball61** は、左手用と右手用の2つに分かれた **分割キーボード** です。右手側には、指で転がしてマウスカーソルを動かす **トラックボール** がついています。

つなぐ順番は次のとおりです。

1. TRRS ケーブル（4極のイヤホンジャックのケーブル）で左右をつなぐ
2. USB ケーブルで、左右のどちらか片方をパソコンにつなぐ

Remap などで変えた設定は、USB ケーブルを差した側のキーボードにだけ保存されるので、USB ケーブルは毎回同じ側に差してください。

> [!WARNING]
> USB ケーブルをつないだまま TRRS ケーブルを抜き差しすると、キーボードの中の部品が壊れることがあります。TRRS ケーブルを抜き差しするときは、**必ず先に USB ケーブルを抜いてください。**

## 2. 基本レイヤー

**レイヤー** は、決まったキーを押している間だけ、キーボード全体のキー配置を切り替える仕組みです。Keyball61 はキーが少ないので、数字や記号はレイヤーを切り替えて入力します。

| レイヤー | 役割 | 入り方 |
| --- | --- | --- |
| 0 | 文字入力 | 何も押していないとき |
| 1 | 数字と移動 | 左手の親指の Space を押している間 |
| 2 | 記号 | 右手の親指のかなキーを押している間 |
| 3 | マウス | トラックボールを動かしたとき |
| 4 | 設定 | 左手の C の下のキーを押している間 |

このドキュメントの配置図は、[Remap](#5-1-remap-でキー配置を変える) の画面を写したものです。図の表示は次のように読みます。

- `▽` は transparent キー
	- レイヤー0 では押しても何も入力されず、他のレイヤーではレイヤー0 と同じキーが入力される
- `Win` は Cmd キー、`Alt` は Option キー
- `Lang 2` は英数キー、`Lang 1` はかなキー

### 2-1. レイヤー0：文字入力

![レイヤー0（文字入力）](./images/layer_0.png)

アルファベットの並びは普通のキーボードと同じです。一番上の数字の段は、レイヤー1 でも数字を入力できるので、使わなくてもかまいません。

左右の親指キーのうち内側のキーは Cmd で、右手の右下の2つのキーは音量を調節するキーです。

次のキーは、タップ（単押し）とホールド（長押し）で動きが変わります。

| キー       | タップ  | ホールド         |
| -------- | ---- | ------------ |
| Q の左     | Tab  | Option       |
| A の左     | Esc  | Ctrl         |
| 左手の親指の左側 | 英数   | Option       |
| 左手の親指の中央 | スペース | レイヤー1（数字と移動） |
| 右手の親指の右側 | かな   | レイヤー2（記号）    |

Option が2つあるのは他のキーとの組み合わせによって使いやすい方を選べるのと、 Option と Tab を同時に使うショートカットを押せるようにするためです。

スペースや Tab を続けて入力したいときは、素早く2回タップして、2回目はそのまま押し続けます。 

また、左右の Shift は素早く2回押すと、Caps Lock が切り替わります。

### 2-2. レイヤー1：数字と移動

左手の親指で Space を押している間の配置です。

![レイヤー1（数字と移動）](./images/layer_1.png)

右手には、電卓のテンキーと同じ並びで数字があり、右下の2つのキーは、画面を暗くする・明るくするキーです。

左手のキーは次のとおりです。

| キー      | 動き                                |
| ------- | --------------------------------- |
| E・S・D・F | 上・左・下・右の矢印                        |
| A・G     | カーソルを行の先頭と末尾に動かす（Cmd + ←・→）       |
| W・R     | カーソルを1単語ずつ左右に動かす（Option + ←・→）    |
| Q       | カーソルの左の1単語を消す（Option + Backspace） |
| T       | カーソルの右の1単語を消す（Option + Delete）    |

### 2-3. レイヤー2：記号

右手の親指でかなキーを押している間の配置です。

![レイヤー2（記号）](./images/layer_2.png)

記号の位置は、記号の英語の呼び名の頭文字などで決めてあります。

| キー  | 記号   | 覚え方                    | キー  | 記号      | 覚え方     |
| --- | ---- | ---------------------- | --- | ------- | ------- |
| Q   | `'`  | quote                  | A   | `@`     | at      |
| W   | `"`  | w-quote                | S   | `*`     | star    |
| E   | `=`  | equal                  | D   | `$`     | dollar  |
| R   | `^`  | raised to the power of | G   | `` ` `` | grave   |
| T   | `~`  | tilde                  | H   | `#`     | hash    |
| X   | `!`  | eXclamation            | N   | `&`     | 'n（and） |
| C   | `:`  | colon                  | L   | `+`     | large   |
| V   | `\|` | vertical bar           | P   | `%`     | percent |
| B   | `\`  | backslash              |     |         |         |

U・I には丸かっこ `( )`、J・K には角かっこ `[ ]` があります。

C のキーは、そのまま押すと `:`、Shift を押しながら押すと `;` になります。これは普通の US キーボードとは逆になっており、Remap の画面でも `;` と表示されますが、そのまま押すと `:` が入力されます。

## 3. マウスレイヤー

### 3-1. オートマウスレイヤー

トラックボールを動かすと、自動でマウス操作のレイヤー（レイヤー3）に入ります。抜けるのは次のどちらかのときです。

- トラックボールを動かさないで 10 秒たったとき
- マウスのレイヤーに置いていないキー（たとえば A）を押したとき。そのキーの文字はそのまま入力される

> [!TIP]
> マウスを使ったあとすぐに J や K を打つと、文字ではなくクリックやスクロールになることがあります。文字を打つ前に **英数キーかかなキーをタップ** すると、確実にマウスのレイヤーから抜けられます。
> 
> また、Shift や Cmd でもレイヤーから抜けてしまうので、これらとクリックを組み合わせたいときは **先に Shift や Cmd を長押しして、トラックボールを動かす** ことで Shift や Cmd と一緒にクリックなどができます。

### 3-2. クリックとスクロール

![レイヤー3（マウス）](./images/layer_3.png)

| キー  | 動き                       |
| --- | ------------------------ |
| J   | 左クリック（押したままボールを動かすとドラッグ） |
| L   | 右クリック                    |
| K・I | 上・下へスクロール                |
| O・U | 左・右へスクロール                |

スクロールキー（K・I・O・U）は、タップすると決まった量だけスクロールし、ホールドすると離すまでスクロールし続けます。**Mac の「ナチュラルなスクロール」の設定によって、向きが逆になります。** 

2つのキーを同時に押すと、次の動きになります。

| 同時に押すキー | 動き                |
| ------- | ----------------- |
| J と K   | 戻る                |
| K と L   | 進む                |
| U と I   | タブを閉じる（Cmd + W）   |
| I と O   | 新しいタブを開く（Cmd + T） |

タブを閉じる・開くの同時押しをすると、マウスのレイヤーから抜けます。これにより、新しいタブでそのまま入力できます。

ボールを転がしてスクロールしたいときは、左手の C の下のキーを押したまま、ボールを転がしてください（[4. 設定レイヤー](#4-設定レイヤー)）。

> [!NOTE]
> Remap の画面では、スクロールキーはカスタムキーのため `User 0`（K）・`User 1`（I）・`User 2`（O）・`User 3`（U）と表示されます。
> 同時押しは、キーの場所ではなく、左クリック・右クリック・スクロールキーの組み合わせで決まっています。Remap でこれらのキーをマウスのレイヤーから消すと、その同時押しも使えなくなります。

## 4. 設定レイヤー

### 4-1. トラックボールの設定

左手の C の下のキーを押している間だけ、設定レイヤー（レイヤー4）に入ります。

![レイヤー4（設定）](./images/layer_4.png)

| キー        | Remap での表示     | 動き                          |
| --------- | -------------- | --------------------------- |
| N         | `Kb 1`         | 設定を保存する                     |
| M・`,`     | `Kb 2`・`Kb 3`  | カーソルを少し速く・遅くする（CPI ± 100）   |
| J・K       | `Kb 4`・`Kb 5`  | カーソルを大きく速く・遅くする（CPI ± 1000） |
| U・I       | `Kb 8`・`Kb 9`  | ボールでのスクロールを遅く・速くする          |
| Backspace | `Clear Eeprom` | 保存した設定とキー配置を削除する（[5-2](#5-2-設定の削除)） |

**CPI** は、ボールを転がしたときにカーソルがどれだけ動くかを表す数値で、大きいほどカーソルが速く動きます。最初の値は 500 です。今の値は、キーボードの小さな画面（OLED）に表示されます。

変えた値は、N を押して保存しないと、USB ケーブルを抜き差ししたときに元に戻ります。

### 4-2. ボールでスクロールする

マイコンの容量を節約するために、設定レイヤー（レイヤー4）はスクロールレイヤーも兼ねています。

そのため、このレイヤーにいる間は、ボールを転がすとカーソルではなく画面がスクロールします。速さは `Kb 8`・`Kb 9` （設定レイヤーの U・I） で変えられます。スクロールキー（マウスレイヤーの K・I・O・U）の速さは変わりません。

## 5. キー配置の変更

### 5-1. Remap でキー配置を変える

[Remap](https://remap-keys.app/) を使うと、ファームウェアを書き込み直さずに、ブラウザからキー配置を変えられます。

1. Chrome などのブラウザで [Remap](https://remap-keys.app/) を開く
2. Keyball61 を Remap に接続する
3. 変えたいキーを選んで、新しいキーを割り当てる
4. 変更をキーボードに書き込む

Remap では、今のキー配置の一覧表を PDF で作ることもできます。覚えるまで印刷して手元に置いておくと便利です。

### 5-2. 設定の削除

設定を最初の状態に戻したいときは、設定レイヤーの Backspace（`Clear Eeprom`）を押します。キーボードが再起動し、次の2つが消えます。

- Remap で変えたキー配置
- 設定レイヤーで保存したトラックボールの設定

この2つは、USB ケーブルを差した側のキーボードの中の **EEPROM**（電源を切っても消えないメモリ）に保存されています。左右両方を戻したいときは、USB ケーブルを差す側を変えて、それぞれで `Clear Eeprom` を押してください。

### 5-3. ファームウェアの書き込み

最初のキー配置や、スクロールキー・同時押しなどの動きは、 **ファームウェア** に書かれています。

ファームウェアを編集すると、Remap よりも自由にキーの動きを設定できます。

ビルドと書き込みの手順は、Keyball 公式リポジトリの説明を見てください。

- https://github.com/Yowkees/keyball/tree/main/qmk_firmware/keyboards/keyball

このフォルダの設定ファイルは次のとおりです。

| ファイル | 中身 |
| --- | --- |
| [keymap.c](./keymap.c) | キー配置、スクロールキーや同時押しなどの動き |
| [config.h](./config.h) | マウスのレイヤーから抜けるまでの時間やスクロールの速さなどの値 |
| [rules.mk](./rules.mk) | ファームウェアに入れる機能（VIA、OLED など） |

書き込んだあとは、左右それぞれで `Clear Eeprom` を押さないと、EEPROM に残っている前のキー配置で動くことがあります。
